# HouseLens 驗證 APK 操作

交付版本：**0.2.2／versionCode 4**，套件 `tw.houselens.probe`。APK 位於 [builds/task14/0.2.2/HouseLens-probe.apk](builds/task14/0.2.2/HouseLens-probe.apk)，SHA-256、簽章指紋、原始碼摘要與建置紀錄位於同目錄 `build-info.json`。這些產物不進 Git。

0.2.2保留放大網站驗證區與縮放操作，新增591固定解析拒絕碼，會顯示於停止原因並保留在ZIP。首次本機驗收已完成；591在0.2.0／0.2.1共4次前景仍0頁未通過。此版補定位資訊，未宣稱採集已修復，詳見 [驗證摘要](summary.md)。其餘六站與背景仍待測。

## 安裝與通知

1. 將 APK 傳到自己的手機，從手機檔案管理員開啟。若系統詢問，僅允許你用來開啟 APK 的來源安裝此測試程式；依手機的安全提示操作。
2. 不需 USB、adb、root 或開發者模式。已有0.1.0／0.2.0／0.2.1時直接更新，不必先解除安裝；本次沿用相同測試簽章。更新後確認原本歷史仍可讀。
3. 開啟「HouseLens 驗證」，應看到版本0.2.2、裝置／Android／WebView資訊、來源與條件欄位。可在手機設定補記One UI、安全更新、省電及App電池設定。
4. 按「設定通知權限」允許進度通知；拒絕也能使用，但通知列可能沒有進度／取消入口，請回 App 按「取消目前作業」。若先前永久拒絕，從手機的 App 通知設定手動開啟。

**解除安裝或清除 App 資料會刪除本機歷史與網站工作階段。** 更新前先主動匯出要保留的紀錄；測試簽章私鑰不隨 APK 交付。

## 本機自檢（不連網站）

1. 按「執行本機自檢」，保持 App 在前景。通常數十秒內結束，可按取消。
2. 正常完成會逐項列出8項 PASS／FAIL：fetch、XHR、iframe 訊息拒絕、延遲舊 ID 重放拒絕、本機資料不列為實站證據、TIMEOUT／RENDERER_GONE 模擬收尾、樣本保存／重讀／ZIP。**先以文字或截圖保留全部結果及樣本runId，再關閉重開**；結果清單只留在本次畫面，ZIP不包含整份自檢清單。若提早失敗，回報實際顯示的項目與錯誤即可。
3. 自檢的網頁與 iframe 回應只來自 App 內建 HTTPS 資產。舊 ID 測項是延遲後重放；不是對真實網站跨導航回應的證明。故障注入標示 SIMULATED，不能證明系統實際終止或 Doze。
4. 在「本機歷史」手動選取自檢列出的 runId，應看到 LOCAL_SELF_CHECK、COMPLETED、1 頁／1 筆、LOCAL1／798.00 萬／28.50 坪。來源「中信」是固定本機樣本設定，背景判讀NOT_TESTED正常。關閉重開再選相同紀錄，確認資料仍在。
5. 按「匯出此筆 ZIP」，選擇手機保存位置。ZIP 只包含 `result.md`、`events.jsonl`、`sample.json`。取消檔案選擇不寫入；寫入失敗或中途取消可能留下空／部分 ZIP，請刪除後手動重試。

自檢不接 Supabase，也不自動上傳。自檢結果頁是本次執行畫面，可直接回報文字或截圖；本機樣本可另行匯出。WebView 不支援必要功能時會 FAIL，請回報版本與失敗項，不要視為手機設定錯誤。

## 單站操作與結果

預設新北中和、最高 2000 萬、最小 20 坪、住宅與 R1,R2，其餘不限；可改永和／新店。數值接受非負數，價格／坪數最多八位整數與兩位小數，屋齡 0–999。代碼依來源支援驗證，無效時不啟動。欄位未知代表未核實，不表示符合條件。

1. 選來源與「前景（最多 3 頁）」，按「開始單站」。每頁成功落盤後增加保存頁數；達 3 頁仍有結果會顯示 TRUNCATED，不等於完整搜尋失敗。
2. 捲到「網站驗證區」，可用雙指或縮放按鈕放大，具體幅度依網頁而定。需要人工驗證時操作網站畫面後按「已完成驗證，繼續同一作業」。HTTP 來源或已失效工作階段不能直接續跑，請取消後重試；人工介入不算背景成功。
3. 結果包括 runId、執行版本、來源／模式／狀態、保存頁數、有效筆數、背景內新頁數、背景判讀、原因及最後保存時間。COMPLETED 只代表所選流程結束；完整性與背景判讀分開核對。無完整保存證據時不算成功。
4. 完成後可點某筆「預覽此張縮圖」。一次只載入一張，顯示圖片成功／失敗；圖片失敗不刪除房源資料，仍可匯出。縮圖解碼尺寸有上限，不載入圖庫。
5. 忙碌時不能開第二作業，請取消或等待完成後手動重試。「七站依序開始」為明確的集合操作，順序固定 591→樂屋→永慶→住商→信義→中信→台灣房屋；失敗／取消／中斷即停止，不自動排隊重跑。

背景測試須等該站前景通過後再做。B1 在第 1 頁保存後切到其他 App，B2 在第 1 頁保存後鎖屏；各保持 10 分鐘、各做兩次。資料不足、提早結束、快取、回前景才完成或人工介入都不能當背景通過。FULL 是正常速率的有界完整輪次，仍可能因來源分頁未知而截斷或證據不足。

## 回報

Task14 開始時先回報安裝版本、裝置／WebView資訊、本機自檢各項結果與能否讀取／匯出 LOCAL_SELF_CHECK 紀錄，再依當輪指示逐站操作。不要一次跑完所有背景案例。

每次實站回報包含來源、行政區、條件、模式、runId、狀態／原因、保存頁數／有效筆數、背景判讀、圖片結果及操作時間。只分享你主動選擇匯出的 ZIP；不需提供帳密、cookie、token 或原始網站整頁。ZIP 無完整地址、標題、完整 URL、圖片 URL 或原始 BFF 本文。

已取得S25+本機自檢全PASS與重開可讀的使用者回報、7份成功匯出樣本。仍未驗證：放大字體、實站原生WebView callback、通知拒絕、檔案選擇器中斷／旋轉、七站實站、背景／鎖屏、系統 timeout／renderer／Doze、更新保留資料。這些需各自實際操作證據，不能用 JVM／Node 或本機樣本填成通過。
